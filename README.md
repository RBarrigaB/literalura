Instrucciones:

Para correr el proyecto, es necesario tener una base de datos y crear el esquema "alura". 
Luego, se debe ejecutar el archivo "base_de_datos.sql" que se encuentra adjunto en el proyecto, con ello se crearán las tablas y constraint necesarios para ejecutar el programa.
Finalmente, se debe agregar la variable "PASSWORD_DB" en las variables de entorno del runner del proyecto y agregar la clave de la base de datos para que springboot pueda acceder a ella. 

Finalmente, solo se debe ejecutar la clase main y el programa ejecutará correctamente, cumpliendo con los requisitos solicitados.
